# SmartAdapter — Cloud Connectivity MVP (Plan v2, agent-ready)

> **Goal:** Send telemetry from the existing ESP32 firmware to a Google Cloud Function (2nd gen, HTTP) that writes the latest state of each device to Firestore — over TLS with server-certificate validation, per-device authentication and allow-listing, and per-device rate limiting — **without ever delaying the breaker logic**. Prove the pipe works end to end.

---

## 0. How to use this document (read first, agent)

This plan is written to be executed by a coding agent. Follow these rules exactly.

> [!IMPORTANT]
> **Approval gate.** Do not modify any file until the human has approved this plan. After approval, execute the phases in order (Section 4). Each phase ends with a checkpoint; do not start the next phase until the checkpoint passes.

### 0.1 Hard rules

1. **Never locate code by line number.** Line numbers in v1 of this plan were brittle. Every edit below is described by an *anchor* (a symbol, include, or function name). Read the whole file before editing and find the anchor yourself.
2. **Never replace an existing function body wholesale.** In particular, `loop()` and `setup()` are edited by *inserting* blocks. Every line that existed before must still exist afterwards (verify with a diff; see Phase 4 checkpoint).
3. **Never write secrets into tracked files.** No real keys, Wi-Fi passwords, or project IDs in `.ino`, `.py`, `.md`, or test files. Tests use obviously fake values generated at runtime.
4. **Never transcribe a certificate from memory.** Root CA PEMs are fetched from Google's PKI repository by a script and fingerprint-checked (Phase 3). The certificate block in plan v1 is corrupted (see Flaw F1) and must not be used.
5. **Do not deploy, flash, push to git, or create cloud resources.** Those are human steps (Phase 6). The agent produces code, tests, a compiled firmware build, and a runbook.
6. **Do not change breaker, relay, threshold, or local HTTP API behaviour.** Additive changes only, plus the explicitly listed moves (secrets into `secrets.h`).

### 0.2 Stop-and-ask conditions

Stop and report to the human (do not guess) if any of the following is true:

- Any identifier listed in Section 3.1 does not exist in the firmware, or has a different type/meaning than assumed.
- The relay's actual on/off state cannot be determined from an existing variable or pin read.
- The firmware already creates FreeRTOS tasks, uses a second core, or calls `WiFi.mode(WIFI_AP)` only (no station mode).
- The board is a single-core variant (ESP32-C3/C6/S2/H2) — the task design still works, but core-pinning values change (see 3.6).
- The ArduinoJson major version or the arduino-esp32 core major version cannot be determined.
- The sketch cannot be compiled with the toolchain found in Phase 0.
- The repo's git history already contains the Wi-Fi password or any key (report it; do not rewrite history).

### 0.3 Final report the agent must deliver

At the end, produce `AGENT_REPORT.md` in the project root containing: Phase 0 recon findings (table of identifiers found), every file created/modified, test results (count passed, coverage %), firmware compile output summary (flash/RAM usage), the root CA fingerprints and their source URLs, any deviations from this plan with justification, and open questions.

## 1. Review of plan v1 — flaws found and how v2 fixes them

Severity: **Critical** = safety, security, or "won't work"; **High** = likely failure in real use; **Medium** = robustness/cost; **Low** = hygiene.

| # | Severity | Flaw in v1 | Why it matters | Fix in v2 |
|---|---|---|---|---|
| F1 | Critical | The GTS Root R1 PEM block is malformed: base64 lines have inconsistent lengths (e.g. lines of 63 characters in a 64-column PEM), so it was almost certainly hand-reproduced and corrupted. | `setCACert` will fail to parse it or validation will fail; every push fails with a TLS error. | CA header is generated by a script from `pki.goog`, fingerprint-verified, and never typed by hand (Phase 3). |
| F2 | Critical | Only GTS Root R1 (RSA) is trusted. Google front ends can serve ECDSA certificates that chain to **GTS Root R4**, and Google rotates intermediates. | Validation can start failing with no code change on your side. | Bundle GTS Root R1–R4 in one PEM string; ESP32's `setCACert` accepts multiple concatenated certs. Verify the live chain with `openssl s_client` before flashing. |
| F3 | Critical | `pushToCloud()` runs inside `loop()`. A TLS handshake on ESP32 typically takes 1–3 s, `setTimeout(5000)` only bounds the *read*, not connect or handshake, and `WiFiClientSecure`'s default handshake timeout is long (120 s in the core versions I'm aware of — verify for the installed core). The comment "never blocked" is false. | While the cloud is slow or unreachable, `readSensorAndCheckBreaker()` and `server.handleClient()` are frozen. **An overcurrent trip can be delayed by seconds to minutes.** This is a safety defect. | Cloud I/O moves to a dedicated FreeRTOS task. `loop()` only copies a telemetry snapshot under a spinlock (microseconds). Explicit connect, handshake, and read timeouts. An acceptance test measures breaker latency while the cloud is unreachable. |
| F4 | Critical | Auth compares header to env var; if `DEVICE_SHARED_SECRET` is unset, a naive `header != os.environ.get(...)` lets a request with *no header* pass (`None == None`). | Unauthenticated writes to your database. | Fail closed: missing/short secret → `500 server misconfigured`, request rejected. Constant-time compare with `hmac.compare_digest`. Dedicated test. |
| F5 | High | Any holder of the shared key can write to *any* `device_id`, and "first push auto-creates the document". | One leaked key (it's in firmware on a physical device) lets anyone create unlimited documents and bypass per-device rate limiting by rotating IDs — unbounded cost. | `ALLOWED_DEVICE_IDS` allow-list (403 otherwise). `device_id` validated against `^[A-Za-z0-9_-]{1,64}$`. Per-device keys noted as a follow-up. |
| F6 | High | `device_id` is only checked for "non-empty string". Firestore treats `/` as a path separator; `.`, `..`, and `__*__` are invalid/reserved IDs. | `device_id: "a/b"` makes `document()` raise or target an unintended path → 500s or odd writes. | Strict regex (F5). Tests for `/`, `..`, `__x__`, over-length. |
| F7 | High | Rate limit is read-then-write without a transaction. | Two concurrent requests both read the old `last_seen` and both write — the limiter doesn't hold under concurrency. | Firestore transaction wraps read + decision + write. Emulator test with two concurrent requests. |
| F8 | High | 3 s server window vs "every 5 s" client schedule measured from push *start*. If one push is slow (cold start, handshake) and the next is fast, arrivals can be < 3 s apart. | Legitimate traffic gets 429s intermittently. | Firmware schedules the next push 5 s after the previous one *completes* and enforces a 2.5 s minimum spacing; server window is configurable and defaults to 2.0 s. 429 returns `Retry-After`; firmware treats 429 as benign. |
| F9 | High | Validation only checks presence, not type. The meter library (field names suggest a PZEM-004T; verify) returns `NaN` on a failed read; ArduinoJson serializes `NaN` as `null` by default, and Python's `json` accepts `NaN`/`Infinity` literals. | Strings, `null`, `NaN`, or booleans (Python `bool` is a subclass of `int`) get written as "numbers"; dashboards break later. | Typed validation. Sensor fields are "finite number **or null**" (null = read failed, stored as such). `threshold` must be a finite number. Booleans must be real booleans. `NaN`/`Infinity` literals rejected at parse time. |
| F10 | High | The payload is written straight through; any extra keys a client sends would be stored. Body size is unbounded. | Arbitrary data injection into Firestore; memory/cost abuse. | Whitelist of known fields only; 2 KB body limit (413); `Content-Type: application/json` required (415). |
| F11 | High | `CLOUD_DEVICE_KEY` (and existing Wi-Fi credentials) live in the `.ino`, and the plan mentions GitHub integration. | Secrets end up in git history. | `secrets.h` (git-ignored) + `secrets.example.h`. Backend secret stored in **Secret Manager** and injected with `--set-secrets`, not a plain env var in a deploy script. |
| F12 | High | Firestore client presumably created at import time; tests "mock Firestore" but importing `main.py` would try to find Google credentials. Time-based tests (4+ s apart) have no clock injection. | Tests fail on a laptop/CI without GCP credentials, or become slow/flaky with `sleep()`. | Lazy client via `get_store()`; injectable clock `_now()`; `FakeStore` for handler tests; transaction body is a plain function tested directly; optional emulator tests. |
| F13 | Medium | A new `WiFiClientSecure` + `HTTPClient` + full TLS handshake every 5 s. Each TLS session needs tens of KB of heap. | Heap fragmentation over hours → allocation failures → push failures or crash/reboot (which also resets breaker state). | One long-lived client in the task, `setReuse(true)` for keep-alive, heap guard (`ESP.getMaxAllocHeap()`), `free_heap` reported in telemetry, 1-hour soak test. |
| F14 | Medium | No handling of HTTP status codes; 401/400 would be retried every 5 s forever. No backoff on network failure. | Log spam, wasted power/data, hammering a broken endpoint. | Status-code policy table (3.7): 401/403/4xx → 60 s + loud log; network/5xx → exponential backoff capped at 60 s. |
| F15 | Medium | `relay_on = !tripped && !manuallyOff` re-derives relay state instead of reading the source of truth. | Cloud shows a state that can disagree with the actual relay (e.g. if another code path drives the pin). | Use the variable/pin the firmware already uses to drive the relay (found in Phase 0). |
| F16 | Medium | "No reconnect → pushes die permanently until power-cycle" overstates it: ESP32 station auto-reconnect is on by default. It *can* get stuck (e.g. hotspot restarts, auth timeouts), so supervision is still worth having. Also, after reconnect the DHCP IP can change and the local dashboard URL silently breaks. | Misleading rationale; IP changes go unnoticed. | Non-blocking supervisor using `WiFi.reconnect()`, escalating to `disconnect()+begin()`; logs the new IP on every reconnect. |
| F17 | Medium | Cost not analysed. One device at 5 s = 17,280 writes/day (+ 17,280 transaction reads). Firestore's free tier is 20k writes/day and 50k reads/day. | Two devices already exceed the free write quota. | Documented (Section 6). `--max-instances=2` caps runaway scaling; budget alert in the runbook; interval is a single constant. |
| F18 | Medium | Cloud Function cold starts can take several seconds; a 5 s client timeout makes the first request after idle fail. | Spurious failures in the demo. | Read timeout 10 s (safe now that it's off the critical path). |
| F19 | Medium | Deploy details missing: `--allow-unauthenticated` (the ESP32 can't mint IAM tokens), runtime, region, service-account roles, Firestore Native mode, security rules. | Deploy "works" but returns 403 from IAM, or Firestore is created in Datastore mode, or rules left open. | Full runbook (Phase 6) including deny-all Firestore rules. |
| F20 | Medium | Only the latest state is kept (`merge=True` on one doc). Trip events between pushes can be missed; a trip is only reported up to 5 s later. | For a breaker, the trip itself is the most important event. | Firmware wakes the cloud task immediately on a `tripped` transition (respecting minimum spacing). A `seq` counter lets you detect dropped pushes. Time-series history is out of scope (Section 7). |
| F21 | Low | Firmware pushes to the placeholder URL `REGION-PROJECT...` if flashed before deploy. | DNS failures every 5 s and confusing logs. | Placeholder detection disables cloud push with one clear log line. |
| F22 | Low | "TLS certificate pinning" is the wrong term; this is root-CA validation. True leaf/SPKI pinning is *wrong* for Google-managed certs, which rotate frequently. | Misleading; someone may later "improve" it into leaf pinning and brick the device. | Renamed to "server certificate validation against bundled root CAs". |
| F23 | Low | Tests 9 and 15 in v1 are duplicates; several important cases (fail-closed, types, bad IDs, 413/415, Retry-After, 500 hygiene) are missing. | False sense of coverage. | Rewritten test matrix (Section 5). |
| F24 | Low | `requirements.txt` pins `flask` separately (it comes with functions-framework) and mixes nothing for tests. `.gcloudignore` misses virtualenvs and caches. | Version conflicts; bloated/unsafe uploads. | Separate `requirements-dev.txt`; fuller `.gcloudignore`. |
| F25 | Low | `StaticJsonDocument` is deprecated in ArduinoJson 7. | Compile warnings or errors depending on installed version. | Agent picks the right form based on the detected version. |

## 2. Target architecture

```
ESP32 (core 1: Arduino loop)              ESP32 (core 0: cloudTask)                 Google Cloud
─────────────────────────────             ─────────────────────────────             ───────────────────────────
server.handleClient()                     wait up to 5 s (or trip notify)
every 1 s: readSensorAndCheckBreaker()    copy snapshot (spinlock)
           publishSnapshot()  ──snapshot──▶ build JSON
if tripped changed: notify ─────────────▶ HTTPS POST (keep-alive, root-CA   ──TLS──▶  Cloud Function "ingest"
Wi-Fi supervisor (non-blocking)             validated, bounded timeouts)              ├ method / auth / type / size
                                          handle status, backoff                       ├ validate + whitelist fields
                                                                                       ├ allow-list device_id
                                                                                       └ Firestore txn: rate-limit + upsert
                                                                                             devices/{device_id}
```

**Invariant:** nothing on core 1 ever waits on the network. The only shared state is a small struct copied under a `portMUX` spinlock.

### 3.2 Backend: `cloud_backend/main.py`

#### 3.2.1 HTTP contract

Endpoint: single HTTP function, entry point `ingest`. Checks run **in this order**; the first failure returns.

| Order | Check | Response |
|---|---|---|
| 1 | Method is `POST` | `405` + header `Allow: POST` |
| 2 | Config valid: `DEVICE_SHARED_SECRET` ≥ 16 chars, `ALLOWED_DEVICE_IDS` non-empty, `MIN_PUSH_INTERVAL_S` parses as float ≥ 0 | `500 {"error":"server misconfigured"}` (details only in logs) |
| 3 | `X-Device-Key` matches secret (constant-time) | `401 {"error":"unauthorized"}` |
| 4 | `Content-Type` is `application/json` (parameters like `; charset=utf-8` allowed) | `415` |
| 5 | `Content-Length` (if present) and actual body ≤ 2048 bytes | `413` |
| 6 | Body non-empty and valid JSON; `NaN`/`Infinity`/`-Infinity` literals rejected | `400 {"error":"invalid JSON"}` |
| 7 | Body is an object; required fields present | `400 {"error":"missing fields","missing":[...]}` |
| 8 | Field types valid (table 3.2.2) | `400 {"error":"invalid fields","invalid":{field: reason}}` |
| 9 | `device_id` in allow-list | `403 {"error":"device not allowed"}` |
| 10 | Rate limit (transactional) | `429` + `Retry-After: <ceil seconds, min 1>` + `{"retry_after_s": x}` |
| 11 | Firestore write | `200 {"status":"ok"}`; on exception `500 {"error":"internal error"}` (no stack trace in body) |

All responses are JSON with `Content-Type: application/json` and `"status"` of `"ok"` or `"error"`. Never echo the provided key. Never log the key.

#### 3.2.2 Payload schema

| Field | Required | Type rule | Notes |
|---|---|---|---|
| `device_id` | yes | str, `^[A-Za-z0-9_-]{1,64}$` | Firestore document ID |
| `voltage`, `current`, `power`, `energy`, `frequency`, `power_factor` | yes (key must exist) | finite number **or `null`** | `null` = sensor read failed |
| `threshold` | yes | finite number | |
| `tripped`, `relay_on` | yes | bool (real JSON boolean) | |
| `device_name` | no | str, ≤ 64 chars | |
| `fw_version` | no | str, ≤ 32 chars | |
| `rssi`, `uptime_s`, `seq`, `free_heap` | no | int (not bool) | diagnostics |
| anything else | — | **silently dropped** | never written |

"Number" means `int` or `float` but **not** `bool`, and `math.isfinite()` true.

#### 3.2.3 Firestore document `devices/{device_id}`

All whitelisted fields present in the request, plus `last_seen: SERVER_TIMESTAMP`. Written with `merge=True` inside a transaction.

#### 3.2.4 Reference implementation

The agent should implement this (adjusting only for real library behaviour it verifies):

```python
"""SmartAdapter telemetry ingest — Cloud Function (2nd gen, HTTP trigger)."""
from __future__ import annotations

import hmac
import json
import logging
import math
import os
import re
from datetime import datetime, timezone
from typing import Any, Optional

import functions_framework
from google.cloud import firestore

MAX_BODY_BYTES = 2048
MIN_SECRET_LEN = 16
DEVICE_ID_RE = re.compile(r"^[A-Za-z0-9_-]{1,64}$")

NULLABLE_SENSOR_FIELDS = ("voltage", "current", "power", "energy", "frequency", "power_factor")
REQUIRED_NUMBER_FIELDS = ("threshold",)
REQUIRED_BOOL_FIELDS = ("tripped", "relay_on")
REQUIRED_FIELDS = ("device_id",) + NULLABLE_SENSOR_FIELDS + REQUIRED_NUMBER_FIELDS + REQUIRED_BOOL_FIELDS
OPTIONAL_STR_FIELDS = {"device_name": 64, "fw_version": 32}
OPTIONAL_INT_FIELDS = ("rssi", "uptime_s", "seq", "free_heap")

log = logging.getLogger("ingest")


class ConfigError(RuntimeError):
    pass


def _now() -> datetime:
    """Injectable clock (tests monkeypatch this)."""
    return datetime.now(timezone.utc)


def _resp(status: int, body: dict, headers: Optional[dict] = None):
    h = {"Content-Type": "application/json"}
    if headers:
        h.update(headers)
    return json.dumps(body), status, h


def _err(status: int, msg: str, headers: Optional[dict] = None, **extra: Any):
    return _resp(status, {"status": "error", "error": msg, **extra}, headers)


def load_config() -> tuple[str, set[str], float]:
    """Read config at request time (not import time) so tests and redeploys pick up changes."""
    secret = os.environ.get("DEVICE_SHARED_SECRET", "")
    if len(secret) < MIN_SECRET_LEN:
        raise ConfigError("DEVICE_SHARED_SECRET missing or shorter than %d chars" % MIN_SECRET_LEN)
    allowed = {x.strip() for x in os.environ.get("ALLOWED_DEVICE_IDS", "").split(",") if x.strip()}
    if not allowed:
        raise ConfigError("ALLOWED_DEVICE_IDS missing or empty")
    try:
        min_interval = float(os.environ.get("MIN_PUSH_INTERVAL_S", "2.0"))
    except ValueError as exc:
        raise ConfigError("MIN_PUSH_INTERVAL_S is not a number") from exc
    if not math.isfinite(min_interval) or min_interval < 0:
        raise ConfigError("MIN_PUSH_INTERVAL_S must be a finite number >= 0")
    return secret, allowed, min_interval


def _is_number(v: Any) -> bool:
    return isinstance(v, (int, float)) and not isinstance(v, bool) and math.isfinite(v)


def _reject_constant(name: str):
    raise ValueError(f"non-finite JSON literal {name} not allowed")


def validate_payload(payload: Any) -> tuple[Optional[dict], Optional[dict]]:
    """Return (record, None) on success or (None, error_body_fields) on failure."""
    if not isinstance(payload, dict):
        return None, {"error": "body must be a JSON object"}
    missing = [f for f in REQUIRED_FIELDS if f not in payload]
    if missing:
        return None, {"error": "missing fields", "missing": missing}

    invalid: dict[str, str] = {}
    device_id = payload["device_id"]
    if not isinstance(device_id, str) or not DEVICE_ID_RE.fullmatch(device_id):
        invalid["device_id"] = "must match ^[A-Za-z0-9_-]{1,64}$"
    for f in NULLABLE_SENSOR_FIELDS:
        if payload[f] is not None and not _is_number(payload[f]):
            invalid[f] = "must be a finite number or null"
    for f in REQUIRED_NUMBER_FIELDS:
        if not _is_number(payload[f]):
            invalid[f] = "must be a finite number"
    for f in REQUIRED_BOOL_FIELDS:
        if not isinstance(payload[f], bool):
            invalid[f] = "must be a boolean"
    for f, max_len in OPTIONAL_STR_FIELDS.items():
        if f in payload and not (isinstance(payload[f], str) and len(payload[f]) <= max_len):
            invalid[f] = f"must be a string of at most {max_len} chars"
    for f in OPTIONAL_INT_FIELDS:
        if f in payload and (not isinstance(payload[f], int) or isinstance(payload[f], bool)):
            invalid[f] = "must be an integer"
    if invalid:
        return None, {"error": "invalid fields", "invalid": invalid}

    record = {f: payload[f] for f in REQUIRED_FIELDS}
    for f in (*OPTIONAL_STR_FIELDS, *OPTIONAL_INT_FIELDS):
        if f in payload:
            record[f] = payload[f]
    return record, None


def rate_limit_retry_after(last_seen: Optional[datetime], now: datetime, min_interval: float) -> Optional[float]:
    """Pure decision function. Returns seconds to wait, or None if the write is allowed."""
    if last_seen is None or min_interval <= 0:
        return None
    elapsed = (now - last_seen).total_seconds()
    if elapsed < min_interval:
        # Clamp: small negative elapsed (clock skew) must not produce a wait longer than the window.
        return min(max(min_interval - elapsed, 0.0), min_interval)
    return None


# ---------- Firestore layer ----------

def _txn_body(transaction, doc_ref, record: dict, now: datetime, min_interval: float) -> Optional[float]:
    """Plain function (unit-testable). Wrapped below with firestore.transactional."""
    snap = doc_ref.get(transaction=transaction)
    last_seen = (snap.to_dict() or {}).get("last_seen") if snap.exists else None
    retry = rate_limit_retry_after(last_seen, now, min_interval)
    if retry is not None:
        return retry
    transaction.set(doc_ref, {**record, "last_seen": firestore.SERVER_TIMESTAMP}, merge=True)
    return None


_txn_write = firestore.transactional(_txn_body)


class FirestoreStore:
    def __init__(self, client: Optional[firestore.Client] = None, collection: str = "devices"):
        self._client = client
        self._collection = collection

    @property
    def client(self) -> firestore.Client:
        if self._client is None:  # lazy: importing main.py must not need GCP credentials
            self._client = firestore.Client()
        return self._client

    def write_if_allowed(self, device_id: str, record: dict, now: datetime, min_interval: float) -> Optional[float]:
        doc_ref = self.client.collection(self._collection).document(device_id)
        return _txn_write(self.client.transaction(), doc_ref, record, now, min_interval)


_store: Optional[FirestoreStore] = None


def get_store():
    global _store
    if _store is None:
        _store = FirestoreStore()
    return _store


# ---------- HTTP entry point ----------

@functions_framework.http
def ingest(request):
    if request.method != "POST":
        return _err(405, "method not allowed", {"Allow": "POST"})

    try:
        secret, allowed, min_interval = load_config()
    except ConfigError as exc:
        log.error("config error: %s", exc)
        return _err(500, "server misconfigured")

    provided = request.headers.get("X-Device-Key", "")
    if not hmac.compare_digest(provided.encode("utf-8"), secret.encode("utf-8")):
        log.warning("unauthorized request")
        return _err(401, "unauthorized")

    if (request.mimetype or "").lower() != "application/json":
        return _err(415, "Content-Type must be application/json")

    if request.content_length is not None and request.content_length > MAX_BODY_BYTES:
        return _err(413, "body too large")
    raw = request.get_data(cache=False)
    if len(raw) > MAX_BODY_BYTES:
        return _err(413, "body too large")
    if not raw:
        return _err(400, "empty body")

    try:
        payload = json.loads(raw, parse_constant=_reject_constant)
    except (ValueError, UnicodeDecodeError):
        return _err(400, "invalid JSON")

    record, error = validate_payload(payload)
    if error:
        return _resp(400, {"status": "error", **error})

    device_id = record["device_id"]
    if device_id not in allowed:
        log.warning("device not allowed: %s", device_id)
        return _err(403, "device not allowed")

    try:
        retry = get_store().write_if_allowed(device_id, record, _now(), min_interval)
    except Exception:  # noqa: BLE001 — never leak internals to the client
        log.exception("firestore write failed for %s", device_id)
        return _err(500, "internal error")

    if retry is not None:
        return _err(429, "too many requests",
                    {"Retry-After": str(max(1, math.ceil(retry)))},
                    retry_after_s=round(retry, 2))

    return _resp(200, {"status": "ok"})
```

Implementation notes the agent must respect:

- Config is read **per request** so tests can change env vars with `monkeypatch`.
- `_txn_body` stays a plain module-level function; tests call it directly with mocks. Do not inline it into the decorator.
- `firestore.SERVER_TIMESTAMP` is a sentinel; tests assert identity (`is`) against it.
- Any Firestore timestamp read back is timezone-aware UTC (`DatetimeWithNanoseconds`); `_now()` must also be aware, otherwise subtraction raises `TypeError`. Add a test that uses aware datetimes.

static void cloudTask(void* /*unused*/) {
  WiFiClientSecure tls;
  tls.setCACert(GOOGLE_ROOT_CAS);
  tls.setHandshakeTimeout(CLOUD_TLS_HANDSHAKE_TIMEOUT_S);

  HTTPClient http;
  http.setReuse(true);                       // keep-alive: avoid a full TLS handshake every push
  http.setConnectTimeout(CLOUD_CONNECT_TIMEOUT_MS);
  http.setTimeout(CLOUD_READ_TIMEOUT_MS);

  uint32_t seq = 0;
  uint32_t failStreak = 0;
  uint32_t delayMs = CLOUD_PUSH_INTERVAL_MS;
  uint32_t lastPushStartMs = 0;

  for (;;) {
    // Sleep until the interval elapses OR loop() signals a trip transition.
    ulTaskNotifyTake(pdTRUE, pdMS_TO_TICKS(delayMs));
    delayMs = CLOUD_PUSH_INTERVAL_MS;

    // Enforce minimum spacing so an early (trip) wake-up can't trip the server rate limiter.
    uint32_t sinceLast = millis() - lastPushStartMs;
    if (lastPushStartMs != 0 && sinceLast < CLOUD_MIN_SPACING_MS) {
      vTaskDelay(pdMS_TO_TICKS(CLOUD_MIN_SPACING_MS - sinceLast));
    }

    if (WiFi.status() != WL_CONNECTED) continue;

    TelemetrySnapshot s;
    portENTER_CRITICAL(&gSnapshotMux);
    s = gSnapshot;
    portEXIT_CRITICAL(&gSnapshotMux);
    if (!s.valid) continue;

    if (ESP.getMaxAllocHeap() < CLOUD_MIN_FREE_BLOCK) {
      Serial.printf("[cloud] skip: low heap (max block %u)\n", ESP.getMaxAllocHeap());
      continue;
    }

    // AGENT: ArduinoJson 6 -> StaticJsonDocument<512> doc;  ArduinoJson 7 -> JsonDocument doc;
    StaticJsonDocument<512> doc;
    doc["device_id"]   = DEVICE_ID;
    doc["device_name"] = DEVICE_NAME;
    setNumOrNull(doc, "voltage",      s.voltage);
    setNumOrNull(doc, "current",      s.current);
    setNumOrNull(doc, "power",        s.power);
    setNumOrNull(doc, "energy",       s.energy);
    setNumOrNull(doc, "frequency",    s.frequency);
    setNumOrNull(doc, "power_factor", s.powerFactor);
    doc["threshold"]  = s.threshold;
    doc["tripped"]    = s.tripped;
    doc["relay_on"]   = s.relayOn;
    doc["seq"]        = ++seq;
    doc["uptime_s"]   = (uint32_t)(millis() / 1000);
    doc["rssi"]       = WiFi.RSSI();
    doc["free_heap"]  = ESP.getFreeHeap();
    doc["fw_version"] = FW_VERSION;

    String body;
    serializeJson(doc, body);

    lastPushStartMs = millis();
    if (!http.begin(tls, CLOUD_INGEST_URL)) {
      Serial.println("[cloud] http.begin failed");
      failStreak++;
      delayMs = min<uint32_t>(CLOUD_PUSH_INTERVAL_MS << min<uint32_t>(failStreak, 4), CLOUD_MAX_BACKOFF_MS);
      continue;
    }
    http.addHeader("Content-Type", "application/json");
    http.addHeader("X-Device-Key", CLOUD_DEVICE_KEY);

    int code = http.POST(body);
    String resp = (code > 0) ? http.getString() : String();
    http.end();

    if (code == 200) {
      failStreak = 0;
      Serial.printf("[cloud] ok seq=%u (%u ms)\n", seq, (unsigned)(millis() - lastPushStartMs));
    } else if (code == 429) {
      Serial.println("[cloud] 429 rate limited (benign)");
    } else if (code == 400 || code == 401 || code == 403 || code == 413 || code == 415) {
      Serial.printf("[cloud] REJECTED %d: %.200s  -> check key / ALLOWED_DEVICE_IDS / payload\n",
                    code, resp.c_str());
      delayMs = CLOUD_CONFIG_ERROR_DELAY_MS;
    } else {
      failStreak++;
      if (code < 0) {
        char tlsErr[96] = {0};
        tls.lastError(tlsErr, sizeof(tlsErr));
        Serial.printf("[cloud] FAILED %s (tls: %s)\n", http.errorToString(code).c_str(), tlsErr);
      } else {
        Serial.printf("[cloud] server error %d\n", code);
      }
      delayMs = min<uint32_t>(CLOUD_PUSH_INTERVAL_MS << min<uint32_t>(failStreak, 4), CLOUD_MAX_BACKOFF_MS);
    }
  }
}

// Non-blocking Wi-Fi supervisor, called from loop().
static void superviseWifi() {
  if (millis() - gLastWifiCheckMs < WIFI_CHECK_INTERVAL_MS) return;
  gLastWifiCheckMs = millis();

  bool up = (WiFi.status() == WL_CONNECTED);
  if (up) {
    if (!gWifiWasUp) {
      Serial.printf("[wifi] connected, IP=%s RSSI=%d\n",
                    WiFi.localIP().toString().c_str(), WiFi.RSSI());
    }
    gWifiDownChecks = 0;
  } else {
    gWifiDownChecks++;
    if (gWifiDownChecks % 6 == 0) {          // ~60 s of failures: hard restart of the STA
      Serial.println("[wifi] still down, restarting station");
      WiFi.disconnect();
      WiFi.begin(WIFI_SSID, WIFI_PASSWORD);
    } else {
      Serial.println("[wifi] down, reconnect()");
      WiFi.reconnect();
    }
  }
  gWifiWasUp = up;
}

## 8. Phase 6 — Deployment and end-to-end verification (human)

Replace `PROJECT_ID` and `REGION` (choose the region closest to where the device runs; use the same area for Firestore). Commands are shown for a shell that supports `\` line continuation; in PowerShell replace `\` with a backtick.

### 8.1 One-time setup
```
gcloud config set project PROJECT_ID
gcloud services enable cloudfunctions.googleapis.com run.googleapis.com cloudbuild.googleapis.com \
    artifactregistry.googleapis.com firestore.googleapis.com secretmanager.googleapis.com
gcloud firestore databases create --location=REGION --type=firestore-native
```
Deploy `cloud_backend/firestore.rules` (Firebase console → Firestore → Rules, or `firebase deploy --only firestore:rules`). Confirm the database is **Native mode**.

Create the device secret. On Windows avoid `echo ... >` in PowerShell (it writes UTF-16 and a trailing newline); use Python:
```
python -c "import secrets; open('secret.txt','w',newline='').write(secrets.token_urlsafe(32))"
gcloud secrets create device-shared-secret --data-file=secret.txt
```
Copy the value into `secrets.h` as `SECRET_CLOUD_DEVICE_KEY`, then delete `secret.txt`.

Grant the function's runtime service account (default: `PROJECT_NUMBER-compute@developer.gserviceaccount.com`, or a dedicated one — recommended) `roles/datastore.user` and `roles/secretmanager.secretAccessor`.

Create a billing budget with an alert (e.g. at a small monthly amount).

### 8.2 Deploy
```
gcloud functions deploy ingest \
  --gen2 --runtime=python312 --region=REGION \
  --source=cloud_backend --entry-point=ingest \
  --trigger-http --allow-unauthenticated \
  --memory=256Mi --timeout=15s --max-instances=2 \
  --set-secrets=DEVICE_SHARED_SECRET=device-shared-secret:latest \
  --set-env-vars=ALLOWED_DEVICE_IDS=socket1,MIN_PUSH_INTERVAL_S=2
```
`--allow-unauthenticated` is required because the ESP32 authenticates with `X-Device-Key`, not IAM. If an org policy blocks public invokers, deployment will warn; resolve that before continuing. Put the resulting URL into `secrets.h`.

### 8.3 Desktop checks before flashing
```
# Chain ends at one of the bundled roots?
openssl s_client -connect REGION-PROJECT_ID.cloudfunctions.net:443 -servername REGION-PROJECT_ID.cloudfunctions.net -showcerts </dev/null

curl ... same request again immediately                                                                                          # expect 429 + Retry-After
curl ... -H "X-Device-Key: wrong"                                                                                                # expect 401
curl -X GET URL                                                                                                                  # expect 405
```

## Appendix A — Changes from v1 at a glance

| Area | v1 | v2 |
|---|---|---|
| Where cloud I/O runs | `loop()` (blocks breaker) | Dedicated FreeRTOS task |

| Secrets | In `.ino` and env var | `secrets.h` (ignored) + Secret Manager |
| Client behaviour | Log and retry every 5 s | Status-code policy, backoff, keep-alive, heap guard, trip wake-up |
| Tests | 15 (with duplicates, time-dependent) | 47 unit + 3 emulator, no sleeps, injectable clock |
| Edits | By line number, `loop()` replaced | By anchor, insert-only, verified by diff |
| Ops | "Deploy later" | Full runbook, rules, IAM, budget, 9 acceptance tests |
